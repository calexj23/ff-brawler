# Project instructions

## Git push authorization

Alex (github.com/calexj23) has authorized Claude to push directly to
`origin` (https://github.com/calexj23/ff-brawler.git) on this repo without
asking for confirmation first. This covers normal pushes to `master` as
part of iterating on the game.

Still ask first for anything destructive or history-rewriting: force pushes,
`git reset --hard`, deleting branches, or amending already-pushed commits.
